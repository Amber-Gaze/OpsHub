# OpsHub
1. 权限管理，不同的模块配置需要申请不同的权限，每个人的权限职能不一样，又分为读写权限，有多层级权限设置
2. 配置管理，每个模块有不同的配置分组，每个配置分组内有多个配置名，每个配置名内可能又有多个配置服务
3. 支持历史修正数据查看，比如查询一段时间内的变动数据，可以将某一个配置回退到某一个历史版本
4. 服务发现，支持服务实例注册与发现，支持健康检查
5. 审计日志，记录用户的操作日志，支持按用户、时间、
操作类型等多维度查询
6. 用户管理，支持用户的增删改查，支持角色分配与权限控制
7. 项目管理，支持项目的增删改查，支持项目成员管理
8. 可视化数据接口，提供统计数据的可视化接口，支持图表展示
